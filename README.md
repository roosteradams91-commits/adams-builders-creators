# Adams Builders and Creators — Source Code

This repository contains the backend functions and tools powering Adams Builders and Creators products.

## Architecture

All products are built on the [Base44](https://base44.com) platform using Deno serve functions.

## Products in this repo

- **Sherlock** — Multi-signal cyberstalking detection tool (PWA + backend)
- **ReviewRocket** — SMS-based Google review collection system
- **AI Act Comply** — EU AI Act compliance checker for SaaS products
- **Cash App Checkout** — Direct payment page for Cash App users
- **Hub Site** — SEO-optimized product catalog at adamscreators.com
